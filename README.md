# 马里奥游戏世界 (Mario Kart World)

一个响应式设计的马里奥主题游戏网站，支持游戏嵌入、多语言切换和流畅的用户体验。

## 网站特点

- **响应式设计**：在各种屏幕尺寸上都能良好显示，包括手机和平板设备
- **游戏嵌入**：使用iframe技术嵌入并展示多种马里奥游戏
- **多语言支持**：支持英文和中文两种语言，可以轻松切换
- **精美界面**：马里奥主题的视觉设计，包含动画和交互效果
- **自定义404页面**：马里奥游戏风格的错误页面

## 项目结构

```
mariokartworld.site/
├── index.html         // 主页
├── 404.html           // 自定义404错误页面
├── css/
│   └── style.css      // 主样式文件
├── js/
│   ├── main.js        // 主要JavaScript功能
│   └── language.js    // 多语言支持功能
└── images/            // 图片资源目录
```

## 页面结构

### 主页 (index.html)

1. **导航栏**：包含网站标志、导航链接和语言选择器
2. **英雄区域**：大型横幅展示区，带有游戏介绍和号召性按钮
3. **游戏展示区**：展示可玩的马里奥游戏，点击后在iframe中加载
4. **角色展示区**：展示马里奥系列的主要角色
5. **新闻区域**：显示游戏和角色相关的最新新闻
6. **页脚**：包含链接、版权信息和通讯订阅

### 404页面 (404.html)

- 马里奥主题的"游戏结束"风格错误页面
- 包含返回主页的按钮

## 多语言支持

网站支持两种语言：

- 英文 (默认)
- 中文

语言设置被保存在浏览器的localStorage中，用户下次访问时会保持他们的语言选择。

## 技术栈

- **HTML5**：使用语义化标签构建页面结构
- **CSS3**：使用Flexbox和Grid进行布局，使用变量、动画等现代特性
- **JavaScript**：原生JS实现交互功能，无需框架依赖
- **响应式设计**：使用媒体查询确保在各种设备上都能良好显示
- **iframe**：用于嵌入外部游戏内容

## 嵌入游戏

主要游戏通过iframe嵌入，目前配置的游戏包括：

1. **Super Mario Bros**：经典平台游戏 (https://jcw87.github.io/c2-smb1/)
2. **Mario Kart**：赛车游戏
3. **Mario Party**：派对游戏

## 本地运行说明

只需将项目文件放在任何可以提供静态文件服务的Web服务器上即可运行。

由于使用了JavaScript模块和现代CSS特性，推荐使用现代浏览器访问，如Chrome、Firefox、Safari或Edge的最新版本。
